# ♻️ Smart Waste Management System

A web-based application designed to simplify waste collection requests and improve waste management through a digital platform.

## 📌 Project Overview

The **Smart Waste Management System** is a web development and DBMS project that allows users to register, log in, view available services, select a waste type, submit waste collection requests, and register complaints.

The system uses PHP for server-side processing and MySQL for database management. It is designed to make waste collection requests easier to submit and manage.

## 🎯 Objectives

- To provide a digital platform for waste collection requests.
- To allow users to select the appropriate waste type.
- To provide user registration and login functionality.
- To enable users to register waste management complaints.
- To display available waste management services.
- To store and manage application data using MySQL.

## ✨ Features

### 1. User Registration and Login
Allows users to register and log in to the website.

### 2. View Services
Allows users to view the waste management services available on the website.

### 3. Waste Type Selection
Allows users to select a waste type when submitting a collection request.

### 4. Waste Collection Requests
Allows users to submit requests for waste collection through an online form.

### 5. Complaint Registration
Allows users to submit complaints related to waste management.

| File | Description |
|---|---|
| `index.html` | Main HTML page |

| `database.sql` | SQL database script |



## 🗄️ Database

The project uses MySQL to store and manage the data required by its features.

The `database.sql` file contains the SQL script used to set up the database. Import it into phpMyAdmin before running the application.

## 🎓 Project Purpose

This project is developed for educational purposes to demonstrate the use of HTML, CSS, PHP, and MySQL in building a web-based application. It also provides practical experience with database connectivity, form handling, and data management.
